# AI ULTRA MUSICFES 2026 / 響鳴電脳祭

Interactive festival poster web demonstration built with kinetic typography, locally inferred YuE2-3B audio tracks, Earshot tactile sound effects, and SIL OFL 1.1 embedded fonts.

- Standalone single-file offline build https://studio-yebisu.github.io/ai-ultra-music-fes/ai-ultra-music-fes.html
